# Annex Track — Conceptual Challenge Log

The Step 4 audit asks precise technical questions about design choices,
and the answers are where the understanding actually lives. A green test
suite proves the code works; it proves nothing about whether the author
can say *why*. These files are the record of those answers.

One file per annex entry. Each numbers its challenges from 1,
independently of the blocks and of the other entries, because an annex
belongs to no block — the same reason its tag carries no block prefix.
